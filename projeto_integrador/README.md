# Projeto integrador

## Questão guarda-chuva
Como políticas de transformação produtiva e orientadas por missões se relacionam
com oportunidades e qualidade do emprego brasileiro?

Linha alternativa: desigualdades ocupacionais de pessoas com deficiência
e acesso a tecnologias assistivas.

## Entregas
- Formulação de problema, pergunta e estimandos;
- Justificativa da escolha metodológica e mapa de hipóteses;
- Modelos e códigos reproduzíveis;
- Avaliação de validade e análises de sensibilidade;
- Relatório final com dados completos, obtidos prioritariamente de fontes oficiais online.

**Importante:** conjuntos agregados de APIs não substituem microdados para inferência individual.
Não versionar bases brutas extensas, nem dados pessoais.
