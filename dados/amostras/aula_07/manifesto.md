# Manifesto de origem — Aula 7

- Natureza: dados inteiramente sintéticos, não derivados de pessoas, empresas ou fontes oficiais.
- Data de elaboração: 2026-11-16; versão: 1.0.
- Regra: 20 identificadores didáticos; seis sucessos (IDs 1 a 6), quatorze insucessos (IDs 7 a 20).
- Gerador opcional: gerar_amostra_07.R; semente fixa 20261116, embora a construção seja determinística.
- Arquivo publicado: coorte_sintetica.csv. O script de análise usa somente esse CSV.
- Pacotes: apenas R base. Não há URL de fonte externa, pois não são dados reais.
- Limitações: não há representatividade, independência empírica demonstrada ou validade externa; não estimar prevalências brasileiras nem impactos causais.
- Dados oficiais completos: somente no relatório final, com documentação de fonte, versão, consulta, microdados e desenho amostral quando necessários.
