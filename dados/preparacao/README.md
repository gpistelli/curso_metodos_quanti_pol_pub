# Construção de amostras (não executar automaticamente)

Adicionar aqui scripts R ou protocolos detalhando obtenção dos dados, URLs oficiais,
período de referência, escolhas de variáveis, tratamento de valores ausentes,
regras de amostragem e sementes. Nenhum desses scripts deve ser dependência
obrigatória dos exercícios. Para cada amostra, manter manifesto e hash.
